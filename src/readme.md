# 💘 Платформа знакомств и общения «You for Me» (REST API + WebSockets)

Современный, высоконагруженный бэкенд для дейтинг-сервиса, реализованный на фреймворке **Django (v5.0+)** с использованием **Django REST Framework** и асинхронного движка **Django Channels**. Проект полностью контейнеризирован с помощью Docker Compose и оптимизирован для безопасной и быстрой работы под нагрузкой.

---

## 🏗️ Архитектура и стек технологий

Проект разделен на слои для обеспечения чистой архитектуры (Clean Architecture):
* **Фреймворк:** Django 5.0+ (REST API + Асинхронный ASGI слой)
* **Асинхронный сервер:** Daphne (обработка HTTP и WebSocket трафика в одном цикле)
* **База данных:** PostgreSQL 15 (хранение профилей, действий, матчей и чатов)
* **Брокер сообщений / Кэш:** Redis 7 (обеспечивает работу WebSocket-групп)
* **Управление окружением:** `django-environ` (изоляция секретов в `.env`)
* **Контейнеризация:** Docker + Docker Compose

## ⚡ Функциональные особенности

### Основной уровень (REST API)
* **Кастомные анкеты:** Профили (`Profile`) с валидацией возраста (18–100 лет), гибкими статусами, интересами и настройками приватности.
* **JWT-авторизация:** Безопасный вход по паре Email + Пароль с помощью `rest_framework_simplejwt`.
* **Единая система оценивания:** Лайки, дизлайки и история просмотров объединены в оптимизированную таблицу `Action` с защитой от дублей (`unique_together`) и селф-лайков на уровне СУБД.
* **Умная лента (Алгоритм ТЗ):** Эндпоинт `/api/profiles/random/` выдает случайного пользователя с учетом заданных фильтров, исключая из выдачи самого себя, приватные профили и анкеты, которые пользователь уже оценивал или просматривал.
* **Оптимизация SQL (Проблема N+1):** Все запросы защищены через `select_related()` и `prefetch_related()`. Подсчет лайков оптимизирован на уровне сериализаторов.
* **Автоудаление медиа (Django Signals):** При удалении фотографии или удалении анкеты целиком, файлы изображений автоматически стираются с жесткого диска.
* **Интерактивный Swagger:** Схема OpenAPI 3.0 и Swagger UI генерируются автоматически через `drf-spectacular`.

### Повышенный уровень сложности (Advanced & WebSockets)
* **Асинхронный Чат реального времени:** Реализован полнофункциональный чат на `AsyncWebsocketConsumer` с маршрутизацией через `ProtocolTypeRouter`. Сообщения мгновенно рассылаются участникам через Redis Channel Layer.
* **Слой бизнес-логики (`services.py`):** Вся тяжелая логика, транзакции, валидация инвайтов на свидания и асинхронное сохранение сообщений изолированы в сервисный слой.
* **Профессиональная Админка:** Кастомизированный интерфейс модератора с предпросмотром фотографий пользователей (Inlines), аватарами в списках и поиском по email.
* **Сид данных:** Management-команда для мгновенного наполнения базы данных 100 уникальными анкетами через `bulk_create` и библиотеку `Faker`.

## 🚀 Инструкция по развертыванию и запуску

### 1. Подготовка окружения
Создайте в корне проекта файл `.env` на основе шаблона `.env.example`:
```env
SECRET_KEY=django-insecure-your-secret-key
DEBUG=True
ALLOWED_HOSTS=localhost,127.0.0.1,web

DB_NAME=dating_db
DB_USER=dating_user
DB_PASSWORD=dating_password
DB_HOST=db
DB_PORT=5432

REDIS_HOST=redis
REDIS_PORT=6379
```

### 2. Сборка и запуск инфраструктуры в Docker
Соберите образы и поднимите контейнеры PostgreSQL, Redis и Django (Daphne) в фоновом режиме:
```bash
docker compose up --build -d
```

### 3. Генерация структуры БД (Миграции)
Создайте таблицы и примените ограничения в PostgreSQL:
```bash
docker compose run --rm --workdir /app/src web python manage.py migrate
```

### 4. Наполнение базы тестовыми данными (100 анкет)
Запустите команду сида для наполнения дейтинг-платформы мок-пользователями:
```bash
docker compose run --rm --workdir /app/src web python manage.py populate_dating
```

### 5. Создание учетной записи Администратора
Для доступа в продвинутую админ-панель создайте суперпользователя:
```bash
docker compose run --rm --workdir /app/src web python manage.py createsuperuser
```

### 6. Прогон автоматических юнит-тестов
Проверьте корректность работы лайков и мэтчинга:
```bash
docker compose run --rm --workdir /app/src web python manage.py test dating_app
```
